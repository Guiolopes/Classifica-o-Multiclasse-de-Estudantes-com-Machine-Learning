# 🎓 Classificação Multiclasse de Estudantes com Machine Learning

## 📌 Sobre o Projeto

Este projeto utiliza técnicas de Machine Learning para prever a situação acadêmica de estudantes universitários, classificando-os em três categorias:

- Graduado
- Matriculado
- Desistente

O objetivo principal é identificar padrões acadêmicos, financeiros e sociais que influenciam a permanência ou evasão estudantil.

O projeto foi desenvolvido utilizando Python e bibliotecas voltadas para análise de dados, visualização e modelagem preditiva.

---

## 🚀 Tecnologias Utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Scikit-Learn


---

## 📊 Etapas do Projeto

### 🔹 Análise Exploratória de Dados (EDA)

Durante a análise exploratória foram avaliadas variáveis como:

- Idade na matrícula
- Estado civil
- Sexo
- Nacionalidade
- Migração
- Curso
- Situação financeira
- Bolsas
- Desempenho acadêmico

Também foram criadas visualizações para identificar padrões entre os grupos de estudantes.

---

### 🔹 Pré-processamento dos Dados

Foram realizadas etapas como:

- Tratamento de variáveis categóricas
- Separação entre variáveis independentes e target
- Organização dos dados para modelagem
- Estratificação das classes

---

### 🔹 Modelagem

O projeto utiliza algoritmos de classificação supervisionada para prever a situação acadêmica dos estudantes.

Entre os pontos trabalhados:

- Separação entre treino, validação e teste
- Controle de overfitting
- Ajuste de profundidade da árvore
- Avaliação de desempenho do modelo

---

## 📈 Métricas Utilizadas

Foram utilizadas métricas fundamentais para classificação:

- Accuracy
- Precision
- Recall
- F1-Score
- Matriz de Confusão

O projeto também aborda a importância de avaliar além da acurácia, principalmente em cenários com classes desbalanceadas.
